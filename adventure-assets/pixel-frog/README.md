# Adventure Art Pack 2.0 — Pixel Frog (CC0)

The PNG files in this folder are genuine authored pixel-art assets from **Pixel Adventure 1** by **Pixel Frog**:
https://pixelfrog-assets.itch.io/pixel-adventure-1

**License:** Creative Commons CC0 1.0 Universal. The original artist explicitly permits commercial use, modification, distribution, and redistribution without mandatory attribution. Credits to Pixel Frog are included here voluntarily.

Original artwork is not generated by URI, OpenAI, or Phaser. Some files were mirrored from the public GitHub copy at:
https://github.com/JonathanGoveira/pixel_adventure_pixel_frog_godot4/tree/main/assets/Pixel%20Adventure%201

## Files

- `frog-*.png`, `pink-*.png`, `virtual-*.png`, `mask-*.png` — four complete character animation sets; idle, run, jump and fall. Each frame is 32×32 pixels.
- `terrain.png` — tile atlas, frame size 16×16 pixels.
- `checkpoint.png` — checkpoint flags, frame size 64×64 pixels.
- `bg-green.png` and `bg-pink.png` — supplied background textures.

URI maps the client's six selectable roles to four character base sprites and applies optional palette tints. No character chooser appears to guests. The actual game sprite is always the one selected in the owner editor. PHP, dynamic image generation services, and paid APIs are **not** required to display the assets.

The runtime loader is `/adventure-real-assets.js`. It preloads static PNG files from the same GitHub Pages origin, sets up Phaser animation frames, and renders tile art. `/adventure-artpack.js` is kept only for original procedural prop/background layers and offline fallback art. Designers may later replace these sprites with URI-owned artwork.
